Automated Backup and Recovery

Automated backup and recovery using AWS EC2, Amazon S3, Bash scripting, and Linux.

"Project Architecture" (architecture.png.jpeg)

Technologies Used

- AWS EC2
- Amazon S3
- Linux
- Bash scripting
- AWS CLI

Key Features

- Creates compressed backup archives.
- Uploads backup archives to Amazon S3.
- Supports recovery by downloading and extracting backups.
